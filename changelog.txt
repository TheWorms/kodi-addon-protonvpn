v0.0.9
- Correctif majeur connexion auto : si l'option est DESACTIVEE, l'addon
  demarre desormais DECONNECTE (un tunnel WireGuard residuel d'une session
  precedente est coupe au demarrage). Avant, le tunnel persistant donnait
  l'impression d'une connexion automatique.
- Correctif auto_connect (quand active) : ne depend plus du dossier supprime
  et se connecte au bon type de config (bug qui l'empechait de fonctionner).
- Reglages > Accueil : bouton 'Ouvrir le menu ProtonVPN' pour lancer
  l'interface (serveurs, stats...) directement depuis les reglages.

v0.0.8
- Liste Serveurs : toutes les configs sont affichees ; le backend non
  actif est GRISE (plus masque) et non connectable d'ici.
- Chaque ligne : bouton Se connecter, ou Se deconnecter sur le serveur actif.
- Drapeau pays sur chaque ligne.
- Accueil : bouton Se deconnecter toujours present (rouge si connecte,
  gris sinon).

v0.0.7
- Nouveau widget Stats en direct (fenetre dediee) : etat, serveur, IP,
  duree, age du handshake, recu/envoye et debit instantane, rafraichi
  chaque seconde. Accessible via l'entree 'Stats' du menu. Retour pour fermer.

v0.0.6
- Apres un import, l'addon ouvre directement la liste Serveurs du backend
  importe (on voit la config tout de suite).
- Detection des doublons : si la configuration est deja presente, un
  message le signale et le fichier existant n'est pas ecrase.

v0.0.5
- Drapeaux pays dans la liste Serveurs (resources/flags/<cc>.png),
  60 pays couverts. Icone par defaut si un pays manque.

v0.0.4
- Arret de Kodi : plus aucun appel a l'API addon pendant le teardown
  (disconnect_on_exit mis en cache) -> journal propre, plus de ligne
  "Unknown addon id" a l'extinction.

v0.0.3
- Reglages reorganises : Accueil / WireGuard / OpenVPN / Avance.
- Protocole par defaut (Accueil) : le backend non choisi est masque
  (serveurs, connexion rapide, test).
- Import dedie par backend (WireGuard / OpenVPN), detection auto du type.
- Dossier de configs cree automatiquement dans userdata/ProtonVPN :
  plus besoin de parcourir userdata (reglage 'dossier' supprime).
- Suppression d'une configuration via le menu contextuel (Serveurs).
- Test de connexion : affiche le pays et l'IP publique si OK.
- Vue Serveurs filtree sur le protocole actif.

v0.0.2
- Correctif : le reglage "Dossier de configurations" (config_folder)
  ne provoque plus l'erreur "error reading the default value" et s'affiche
  bien dans l'onglet Configuration (ajout de allowempty).
- get_addon() et la lecture des reglages tolerent l'arret de Kodi
  (plus d'erreur "Unknown addon id" a l'extinction).
- WireGuard : l'IPv6 est retire de la config avant wg-quick pour eviter
  l'echec ip6tables (table 'raw' absente) sur CoreELEC.

v0.0.1
- Première version publique.
- Choix explicite WireGuard ou OpenVPN (deux entrées distinctes).
- Saisie des identifiants OpenVPN/IKEv2 (non requis pour WireGuard).
- Import de fichiers de configuration (.ovpn et .conf), jusqu'à 10.
- Connexion à une configuration : test puis connexion, état actif visible.
- Bouton « Tester la connexion ».
- Vue Stats / Journaux : état, durée, handshake, IP, débit reçu/envoyé,
  journal des événements.
- Indicateur d'état VPN exposé pour le header du skin (propriété de fenêtre).
- Quelques réglages : protocole par défaut, connexion auto, reconnexion auto,
  déconnexion à la fermeture, NetShield/NAT (OpenVPN), pays par défaut.
- Service de fond : surveillance, reconnexion à backoff, machine à états.
